## Lotto 프로젝트 개요
Lotto 프로그램은 사용자로부터 1000원 단위로 로또 구입 금액을 입력받아 로또를 발행합니다.<br>
사용자는 당첨 번호와 보너스 번호를 입력하고, 해당 번호들로 로또 당첨 여부를 확인합니다.<br>
그리고 당첨내역과 수익률을 출력한 후 종료됩니다.

로또 당첨 기준과 금액은 다음과 같습니다.
  
|등수|기준|금액|
|------|---|---|
|1등|6개 번호 일치|2,000,000,000원|
|2등|5개 번호 + 보너스 번호 일치|30,000,000원|
|3등|5개 번호 일치|1,500,000원|
|4등|4개 번호 일치|50,000원|
|5등|3개 번호 일치|5,000원|

- 로또 한 세트는 1부터 45까지의 숫자 중 중복되지 않는 6개 숫자로 구성되어 있습니다.
  - ex. `[1, 3, 5, 7, 8, 13]`

## 기능목록
### 1. 출력 기능
  - [X] 1.1 구입 금액 안내하는 기능
  - [X] 1.2 구매한 로또를 보여주는 기능
  - [X] 1.3 당첨 번호 입력을 안내하는 기능
  - [X] 1.4 보너스 번호 입력을 안내하는 기능
  - [X] 1.5 당첨 내역을 출력하는 기능
  - [X] 1.6 수익률 출력하는 기능

### 2. 입력 기능
  - [X] 2.1 구입 금액을 입력하는 기능
  - [X] 2.2 당첨 번호를 입력하는 기능
  - [X] 2.3 보너스 번호를 입력하는 기능

### 3. 랜덤 번호 생성 기능 (로또 생성)
  - [X] 3.1 6개의 로또 번호를 랜덤으로 추출하는 기능
  - [X] 3.2 로또 번호를 오름차순으로 정렬하는 기능 

### 4. 당첨 여부 확인 하는 기능
  - [X] 4.1 당첨 번호와 로또 번호 비교하는 기능
  - [X] 4.2 보너스 번호 일치 여부 확인
  - [X] 4.3 등수를 구하는 기능

### 5. 수익률을 계산하는 기능
  - [X] 5.1 수익률 계산하는 기능

### 6. 유효성 검증 기능
  - [X] 6.1 구매 금액 입력 확인
     - [X] 6.1.1 빈값인 경우
     - [X] 6.1.2 음수인 경우
     - [X] 6.1.3 정수가 아닌 경우
     - [X] 6.1.4 공백이 있는 경우
     - [X] 6.1.5 1000원 단위가 아닌 경우
  - [X] 6.2 로또 번호의 범위가 1에서 45 사이인지 확인
  - [X] 6.3 로또 번호가 중복되지 않고 뽑혔는지 확인
  - [X] 6.4 당첨 번호 입력 확인
     - [X] 6.4.1 빈값인 경우
     - [X] 6.4.2 당첨 번호가 중복되지 않는지 확인
     - [X] 6.4.3 당첨 번호가 6개가 아닌 경우(6개 초과 또는 미만)
     - [X] 6.4.4 ',' 구분자 외의 다른 문자가 있는 경우
     - [X] 6.4.5 정수 입력이 아닌 경우
     - [X] 6.4.6 음수인 경우
     - [X] 6.4.7 구분자 사이에 공백이 있는 경우
  - [X] 6.5 보너스번호와 당첨 번호 중복 여부 확인
